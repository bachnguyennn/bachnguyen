TL;DR

A ResNet50 pneumonia screener tuned for 96.9% recall — catching almost every case — with Grad-CAM overlays so you can see it's looking at the lungs, not the labels.

⚠ for research & education only — not validated or intended for clinical diagnosis.

# 01 — the question I wanted to answer
In [2]:

I wanted to build a pneumonia screener for chest X-rays — but the framing I cared about wasn't "what's the highest accuracy?" In screening, a missed pneumonia case (false negative) is far more dangerous than a false alarm.

So the real question was: can I build a model that catches almost every pneumonia case, stays honest about its false alarms, and can show me where it's looking so I can trust it?

# 02 — getting to know the data
In [3]:

The dataset is the Kaggle pediatric chest X-ray set (Guangzhou Women and Children's Medical Center). Two things jumped out:

  • It's imbalanced — far more pneumonia images than normal. A model that just guesses "pneumonia" scores deceptively well on accuracy, which ruled accuracy out as my headline metric.
  • Images vary in contrast, positioning, and artifacts — the kind of thing that fools a model into learning a label in the corner instead of the lungs.

That set the whole design: imbalance handling, a precision-recall view, and a way to see what the model attends to.

# 03 — how I thought about it
In [4]:
  1. Backbone — ResNet50 with ImageNet transfer learning: strong features and a clean final conv block ideal for class-activation maps.
  2. Imbalance — weighted random sampling + weighted cross-entropy so the minority "normal" class isn't drowned out.
  3. Training — freeze backbone, train the head, then fine-tune later layers; save the best checkpoint by validation F1, not accuracy.
  4. The tradeoff, on purpose — tune toward high pneumonia recall, accepting more false positives. In screening that's the right error to make.
  5. Trust — Grad-CAM + Eigen-CAM overlays so every prediction comes with a visual of its evidence.

# 05 — the honest verdict
Out[8]:
verdict: The model does what a screener should — high sensitivity, with its reasoning on display. I documented the failure cases (12 false negatives, 48 false positives) because in medical AI those are the most important images to study. A strong research prototype, not a clinical device — and I'm explicit about that. The takeaway: defining the right error before training mattered more than any architecture choice.
