# Personal Website (Astro)

Minimal professional portfolio built with Astro and deployed to GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content editing

- Projects: `src/content/projects/*.md`
- Blog posts: `src/content/blog/*.md`

## Resume

Add your PDF resume at `public/resume.pdf`.
